How it works

1. Negative selection. Random detectors are created. Any detector that overlaps a known self point is deleted, so survivors only cover non-self space.

2. Detection. Each new antigen is checked against all detectors. A hit on a normal antigen is a false alarm. A miss on an attack means infection.

3. Clonal selection. A detector that catches an attack becomes a memory cell and spawns mutated clones near it. The detection rate for that pathogen climbs over time.
